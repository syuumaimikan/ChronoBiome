# ChronoBiome

「ルールと生態系」から、創世から悠久の時間まで現実のように変わり続ける世界を自動生成し、3D ローポリで観測・プレイするブラウザツール。

設計の全体像は [docs/DESIGN.md](docs/DESIGN.md) を参照。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 決定論・現実性・性能予算のテスト
npm run build    # 型検査 + 本番ビルド
```

- **観測** — ドラッグで移動、右ドラッグで回転と傾き、ホイールで拡大。地表をクリックするとセルの詳細。下のバーで時間レンズ（宇宙〜現在）と再生速度を切り替える。
- **地表へ降りる** — そのまま拡大し続けるか「降り立つ」ボタン（または高度 20 km 以下で Enter）で、惑星から地上まで連続でズームして歩ける。
  高度 2,200 km より下ではシミュレーションのセルから補間した連続地形になり、地上近くでは森・草・岩・動物の群れ・空・霧・昼夜が現れる。
  - 歩行: `W A S D` 移動、`Shift` 走る、`Space` ジャンプ、`F` 飛行（`Space`/`C` で上下）、ドラッグで見回す、ホイールでカメラ距離（寄りきると一人称）、`Esc` で上空へ。
  - 海に入ると泳ぐ。HUD のスライダーで現地時刻を変えられ、歩いている間は時刻が進む。
  - 見た目はルールパックの各バイオームの `surface`（地面色・樹種と密度・草・岩・動物の体型と密度）で決まる。省略したバイオームは気候から自動で決まる。
- **ルール** — ルールパック（JSON）を編集。入力中に検証され、エラーは位置付きで表示される。「このルールで生成」で反映。

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/core` | 純 TypeScript のシミュレーション（DOM 非依存・決定論） |
| `src/core/rules` | ルールパックのスキーマ、安全な式言語、同梱パック |
| `src/core/world` | 測地線グリッド、セル集合の抽象、ワールド状態 |
| `src/core/systems` | 地形・気候などの各システム |
| `src/worker` | Web Worker でシミュレーションを実行 |
| `src/render` | Three.js によるローポリ描画と層の配色、カメラと歩行操作（`explorer.ts`） |
| `src/render/surface` | 地表ビュー: 地形サンプラー、立方体球の四分木 LOD、植生、動物、空、プレイヤー |
| `src/ui` | Preact の画面 |
