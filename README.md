# ChronoBiome

「ルールと生態系」から、創世から悠久の時間まで現実のように変わり続ける世界を自動生成し、3D ローポリで観測・プレイするブラウザツール。

天体・地殻・気候・生命・文明（経済・技術・建築・国家・文化・宗教・戦争・疫病）・魔法・占星術・宇宙進出が同じ時間の上で同時に動き、互いに影響し合います。
設計の全体像は [docs/DESIGN.md](docs/DESIGN.md) を参照。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 決定論・現実性・魔法・天体・書き出しのテスト
npm run build    # 型検査 + 本番ビルド
```

### 観測

- **時間** — 下のバーの ▶ で再生。時間レンズは「自動」が既定で、生命が単純なうちは 1 tick = 1000 万年、動物が現れると 100 万年、知性種が現れると 200 年、文明が進むと 20 年 → 1 年と自動で細かくなる。速度 ×100 まで。
- **カメラ** — ドラッグで移動、右ドラッグで回転と傾き、ホイールで拡大。拡大しきるか「降り立つ」（Enter）で地上に降りて歩ける。
- **クリック** — 地表をクリックするとその地点の自然・土地利用・住む生き物、町の印をクリックすると町の詳細、地上で動物をクリックするとその種の詳細（図鑑に記録）を右のパネルに表示。
- **右のパネル**
  - 世界: 主星・気候・生命・文明の要約と推移グラフ、時間の分岐点（保存した時点に戻ると別の歴史が始まる）
  - 年代記: 出来事を種類別に。⌖ でその場所へ、🔍 でその生物へ
  - 地点 / 生物 / 町: 詳細カード。生物は体型の図・食性・適温・個体数・分布・系統・食物網、町は人口・市場の物価と需給・研究と建設の進み具合・建物・技術・価値観・人物
  - 国家: 主な国（政体・人口・首都）と大きな町。地図の「国と領土」層で版図を表示
  - 技術: 約 100 の技術を時代別に。発明済み・研究可能・未到達
  - 天空: 実際の軌道計算から出した夜空（星座・黄道・惑星）、月相、アスペクト、今後の食・会合・彗星、恒星系の配置
  - 魔法: 部品をつないで呪文を組む（Arcane ルールのみ）。必要マナ・暴発率を自動で見積もり、選んだ地点で唱える
  - プレイ: その時代の町に一人の人間として生まれ、売買・寄進・移住・発掘・観察。寿命が来たら次の人生へ（前世の行いは世界に残る）
  - 実験: いまの世界に災厄を起こす（巨大隕石・超巨大噴火・大疫病・太陽嵐・氷期・黄金時代・恒星の膨張）、別シードの世界を並行計算して比較
  - 書き出し: 世界 JSON、設定資料 Markdown、地図 PNG、ルールパック、ワールド・カートリッジ（単体で遊べるテキスト RPG の HTML）
  - AI: ローカル LLM（Ollama / OpenAI 互換）の接続。年代記の物語化・図鑑の解説・言葉からの呪文・世界への質問。なくても全機能が動く
- **層** — 自然（バイオーム・標高・プレート・地殻・気温・湿潤度・種の多様性）と生き物と人（国と領土・人口密度・土地利用・種の分布・マナ）。

### 文明が自律的に進むもの

知性種の誕生（社会性のある温血の雑食動物の知能が上がり続けた先）から先は、すべて自動です。

- 人口は食料（生態系の生産力・農業技術・灌漑）で決まり、余れば増え、溢れると新しい町を作る。海を渡るには航海術が要る
- 町は需要と価値観に応じて研究する技術を選び、交易路・移住・文字を通じて発明が広がる。人口が減ると失われる
- 建物は不足（食料・防衛・信仰・研究）から優先度を決めて建てる。滅びた町は遺跡になり、遺物が埋まる
- 国は町をまとめ、部族 → 首長国 → 王国 → 帝国・共和国などへ移り、資源と価値観・宗教の違いから戦争し、征服・分裂する
- 宗教は飢饉・疫病・日食などを引き金に生まれ、言語は隔離で分岐する
- 疫病は家畜化や開墾で人に移り、交易路で広がる。医学・衛生・ワクチンで抑えられる
- 化石燃料の排出が CO2 と気温を上げ、再生可能エネルギーで下がる。宇宙港から他の惑星へ植民する

### ルール

「ルール」タブでルールパック（JSON）を編集。入力中に検証され、エラーは位置付きで表示。同梱は「Earth-like（魔法なし）」と「Earth-like + Arcane（魔法あり）」で、観測画面の左上からも切り替えられる。

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/core` | 純 TypeScript のシミュレーション（DOM 非依存・決定論） |
| `src/core/rules` | ルールパックのスキーマ、安全な式言語、同梱パック |
| `src/core/world` | 測地線グリッド、セル集合の抽象、ワールド状態 |
| `src/core/universe` | 恒星系の生成、ケプラー軌道、恒星進化 |
| `src/core/systems` | 地形・気候・生態と進化・文明・魔法・占星術 |
| `src/core/play` | プレイヤーの行動と災厄シナリオ |
| `src/worker` | Web Worker でシミュレーションを実行、UI への問い合わせ |
| `src/render` | Three.js によるローポリ描画、層の配色、カメラと歩行、町と建物（`towns.ts`） |
| `src/render/surface` | 地表ビュー: 地形、植生、種から作る動物、空、プレイヤー |
| `src/llm` | ローカル LLM（任意） |
| `src/export` | 地図 PNG とワールド・カートリッジ |
| `src/ui` | Preact の画面（`panels/` が右の詳細パネル） |
