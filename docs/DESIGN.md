確定した方針: **ブラウザアプリ** / **ローカル LLM + ルール** / **創世から悠久まで** / **現実世界の再現を志向** / **3D ローポリ** / **軽量かつ高速**。

## 中心となる設計原則

- **全レイヤーが常に生きている。** 時代で切り替わるのではなく常に同時に走り、変わるのは時間の倍率だけ（「時間レンズ」）。
- **因果ループを閉じる。** 天体 → 気候 → 地形 → 生態 → 進化 → 文明（経済・技術・建築）→ 排出・土地利用 → 気候・生態へ戻る。
  魔法と占星術も例外処理ではなく、同じ場（フィールド）と式の仕組みに乗る自然法則として扱う。
- **進化のアルゴリズムは 1 つだけ作って使い回す。** 「形質ベクトル + 変異 + 選択 + 隔離による分岐 + 系統樹」を
  汎用の複製子エンジン (`core/replicator.ts`) にし、生物のゲノム・病原体・言語・価値観・宗教の全てがこれに乗る。
- **システムは「セル集合 + 隣接表」にだけ依存する。** 地表も地底も深海も高空も、他の天体も、同じ system がそのまま動く。
- **現実の法則を既定値にする。** 既定ルールパック「Earth-like」は経験則で較正する
  （ケプラー軌道、気温減率 6.5℃/km、CO2 倍増あたりの昇温、Whittaker のバイオーム区分、Kleiber の代謝則、
  栄養段階間のエネルギー転送効率 約10%、需給による価格形成、技術普及の S 字曲線）。
- **シミュレーションが唯一の真実、LLM は「解釈と執筆」だけ。** LLM は tick ループに入れない。
  数値状態は「シード + ルールパック + 介入ログ」から決定論的に再現でき、LLM の出力はキャッシュして固定する。
- **LLM が落ちていても全機能が動く。** 命名は音節ベースの手続き生成、文章はテンプレートにフォールバック。
- **ルールはデータ。** 検証済み JSON。`eval` は使わず、安全な式評価器と呪文インタプリタで解釈する。
- **コアは純 TypeScript（DOM 非依存）。** 同じコードが Web Worker・ヘッドレス検証・テストで動く。

## 軽量・高速のための方針

- **データ**: 全状態を TypedArray の SoA で持つ。tick 中のオブジェクト生成はゼロ。隣接は事前計算した `Int32Array` テーブル。
- **多段レート**: 遅い系（プレート・侵食）は低頻度、速い系（市場）は毎 tick。変化したセルだけ再計算する dirty 領域管理。
- **スレッド**: シムは Web Worker。描画スレッドには変更された層だけを transferable で渡す。Lab のバッチは Worker プール。
- **描画**: 惑星は 1 メッシュ + 頂点カラー（層の切替は色バッファの書き換えだけ、ジオメトリ再構築なし）。
  生物・木・建物は `InstancedMesh`。モデルは全て手続き生成で外部アセットなし。フラットシェーディング、テクスチャなし、影は任意。
- **遅延**: 他の天体は初めて観測・訪問されるまで生成しない。活動のない天体は粗い近似で進める。大きなデータ（技術ツリー等）と各画面は遅延ロード。
- **依存を絞る**: three / preact / zod / idb / comlink のみ。乱数・ノイズ・軌道計算・式評価器は自前実装。
- **予算**: 初期 JS 約 350KB gzip 以内、現在レンズ 1 tick 8ms 以内、内蔵 GPU で 60fps。計測をテストに含め、超えたらそのホットパスだけ WASM 化を検討する。

## ワールドモデル

- **ユニバース**: `恒星(質量・光度・年齢), 天体[](軌道要素・質量・半径・自転傾斜・大気・衛星), 背景恒星(星座用)`
- **ワールド（天体ごと）**: 球面の**測地線グリッド**（正二十面体を細分、既定レベル 6 = 約 4.1 万セル、各セル隣接 5〜6）。
  層: `plateId, elevation, sediment, 岩種, 鉱床, temperature, moisture, flow, ice, soil, npp, biomeId, landUse, infra, mana`
- **大気と炭素**: 天体ごとの `CO2, 大気圧, 海洋炭素, 氷床量, 海面`
- **種テーブル**: `id, parentId(系統), 出現/絶滅 tick, genome, 原産天体`
- **個体群**: `(speciesId, cell) → 密度` の疎配列
- **集落**: `id, 天体, cell, 種族, 人口, 在庫[財], 価格[財], 知識[技術→進捗・普及率], 建物[], 建築キュー, 所属政体`
- **建物**: `種別, 建設 tick, 状態(建設中/稼働/荒廃/遺跡), 耐久`
- **交易路**: 集落間エッジ（地上は地形コスト経路、惑星間は Δv コストと遷移窓）
- **追加層セル**: 地底空洞・深海底・高空・軌道。存在する場所だけ疎に確保し、縦穴などの上下リンクと横の隣接を持つ
- **文化**: 集落ごとの `言語ベクトル(音韻・語彙傾向), 価値観ベクトル(好戦性・自然崇拝・商業重視…), 宗教[]`。言語・宗教にも系統樹
- **病原体・共生体**: 種テーブルの特殊な種。`感染力・致死率・潜伏期間・適温・宿主域` のゲノムと、セル/集落ごとの感染区分 (S/I/R)
- **遺物**: `種別(碑文・設計図・魔導書), 由来集落, 言語, 内容(技術ID / 呪文AST / 年代記イベント), 位置と埋没深度`
- **人物**: 憑依対象や歴史上の人物だけを個体として記録（出生図・能力・所持品・業績）。それ以外の住民は集計値のまま
- **ゴーレム**: `素体(素材・耐久・マナ容量), 行動ルーチン(呪文AST), 位置, 所有者`
- **呪文庫**: 呪文 AST の集合（文明・プレイヤーごと）
- **年代記** と **介入ログ**（決定論再生のための入力）

## 柱ごとの設計

### 1. 天体システム (`universe/`, `systems/celestial`)

- 恒星系をシードとルールから生成。軌道はケプラー要素の解析解（数値積分なしで任意時刻の位置が出るので軽い）。
- 惑星への日射は軌道距離・離心率・自転傾斜から算出 → 季節と緯度別気温。軌道要素の長周期変動（ミランコビッチ周期）が氷期を駆動。
- 衛星は潮汐と食を生む。小惑星帯は隕石衝突イベントの発生源。
- 恒星は年齢とともに光度が変わる（悠久の時間で居住可能域が移動し、やがて世界の終わりが来る）。
- 任意の天体・緯度経度から見た空（天球上の位置）を返す `sky.ts` が、占星術と空の描画の共通基盤。

### 2. 地殻変動 (`systems/terrain`)

- **プレート運動**: 球面上でプレートを回転移動。収束境界で造山・沈み込み、発散境界で地溝・海嶺、ホットスポットで火山島。
- **侵食と堆積**: 流量比例の河川侵食（stream power 則）、斜面崩壊、低地・河口への堆積。
- **河川**: 標高から流向と流量累積を再計算。地形が変われば流路も変わる。
- **突発**: 噴火・地震・津波・洪水。人間スケールの時間でも地形が動き、建物を壊し、火山灰が気候を冷やす。
- **人為**: 伐採・灌漑・採掘が `landUse` と侵食率を変える。

### 3. 気候変動 (`systems/climate`)

- **エネルギー収支**: 日射、アルベド（氷・雲・植生）、温室効果から緯度別気温を解く。氷-アルベドのフィードバックで全球凍結や暴走温暖化が起こりうる。
- **炭素循環**: 火山からの放出、岩石風化による吸収、海洋との交換、生物圏の固定、文明の排出（燃料・伐採）を収支で追う。
- **大気と水**: 緯度帯の卓越風、山脈の風下の乾燥、海からの距離で降水を決める。
- **氷床と海面**: 氷床量に連動して海面が上下し、陸橋の出現・水没が種の移動と交易路を変える。
- **人為的気候変動**: 産業化で CO2 が増え、気温・海面・農業収量・生態系に返ってくる。技術（再生可能エネルギー等）や魔法で緩和もできる。

### 4. 生態と進化 (`systems/biosphere`)

- **ゲノム = 連続形質ベクトル + 離散的な革新。** 連続形質は体サイズ・適温・適湿・繁殖率・分散力・食性幅・マナ親和など。
  革新は光合成・多細胞・陸上進出・飛翔・恒温・知性など（前提条件と獲得確率はルール）。
- **自然選択は適応度から創発。** セルごとの適応度（環境適合 × 餌の得やすさ − 捕食圧 − 競争）が増殖率を決め、有利な変異が広がる。
- **生態動態**: NPP から環境収容力、相互作用ルールから捕食・競争・共生項を作る一般化ロトカ=ヴォルテラ系。代謝は Kleiber 則。
- **種分化**: 地理的隔離（海・山脈・氷床・別の天体）と形質乖離が閾値を超えたら分岐。系統樹に記録。
- **絶滅と適応放散**、捕食者と被食者の**共進化**。

### 5. 経済 (`systems/society`)

- 「知性」の革新を持つ種が一定密度に達すると集落が発生。
- 資源は世界から来る（食料・木材は生態系、鉱石は地質、マナ結晶はマナ場）。財と生産レシピはルールで定義。
- 人口が労働を配分して生産・消費。集落ごとに価格を持ち、超過需要で毎 tick 更新。
- 価格差が輸送費を上回ると財が流れる。河川・海岸・峠・道が交易路を決める。
- 現在レンズでは 1 tick = 1 日で物価・交易量・人口がライブで動き、プレイヤーの売買も価格に効く。

### 6. 技術の進歩 — 現実の技術史の粒度 (`systems/society/tech.ts`, `adoption.ts`, `data/tech/`)

- **数百ノード規模の技術グラフ**を分野別データで持つ:
  農業・食料 / 材料・冶金 / エネルギー / 道具・機械 / 輸送 / 建築・土木 / 通信・記録 / 数学・自然科学 / 医療 / 軍事 / 統治・金融 / 計算機 / 宇宙。
  例: 火 → 土器 → 製銅 → 青銅 → 製鉄 → 鋼 → 蒸気機関 → 内燃機関 → 電力 → 半導体 → 計算機 → ロケット → 軌道到達 → …
- **各ノード**: `前提技術(AND/OR), 必要資源へのアクセス, 成立条件(人口密度・識字率・余剰などの式), 研究コスト, 維持人数, 効果`。
- **発見と発明を分ける。** 科学的発見（知識）と工学的発明（応用）を別ノードにし、発明は対応する発見を前提にできる。
- **発明 ≠ 普及。** 技術ごとに集落内の普及率を持ち、S 字曲線で広がる。効果は普及率に比例する。
- **学習曲線**: 累積生産量に応じてコストが下がる。
- **エネルギー転換**: 薪 → 石炭 → 石油 → 電力 → 原子力 → 再生可能 → 核融合。各エネルギー源は資源・収支・排出量を持ち、気候に返る。
- **伝播と喪失**: 交易路・移住・文字・印刷・通信で伝わる速度が変わる。人口崩壊で維持人数を割ると失われる。
- **地理が歴史を決める**: 錫のない大陸では青銅器が遅れる、家畜化できる種がいなければ農耕が遅れる、など資源と生態から分岐する。
- 時代区分は到達技術集合からの派生値。ルールパックで別の技術史（魔導文明など）に差し替え・追加できる。

### 7. 建物の建築 (`construction.ts`, `infrastructure.ts`)

- 建物種別はルールで定義: `必要技術, 建設コスト(財 + 労働), 立地条件(式), 維持費, 効果`（住居・貯蔵・生産・研究・防衛・交易・マナ集積・発射場…）。
- 集落は不足（住居、食料不安、防衛）から優先度を計算し、数 tick かけて建てる。維持できなければ荒廃し、滅びれば**遺跡**として残る。
- 野営地 → 村 → 町 → 都市 → 巨大都市 と成長。道・橋・運河・港・灌漑・城壁・鉄道は `infra` 層に建ち、輸送コストと交易路を変える。
- **3D 表現**: 建物は部品（基礎・壁・屋根・塔・煙突など）の組み合わせで手続き生成するローポリモデル。技術時代と文化で部品セットが変わる。
  建物リストから決定論的に街区レイアウトを生成。プレイヤーも建築できる。

### 8. 魔法システム — 部品の組み合わせで無限に作る (`systems/magic`)

呪文は固定リストではなく、**小さな部品をつないだグラフ（型付きデータフロー）**。ルールパックで無効にすれば純粋な現実再現になる。

- **マナ場**: グリッドの `mana` 層。湧出源はルール（既定: プレート境界の霊脈、火山、古い森、天体配置）。拡散し、使えば減り、ゆっくり回復する有限資源。
- **部品の種類**:
  - **源**: 周囲のマナ / 結晶 / 生命力 / 天体 / 触媒となる財
  - **属性**: 火・水・地・風・生命・精神・時空など（ルールで追加可）
  - **形**: 接触 / 投射 / 範囲 / 結界 / 付与 / 儀式（広域・長時間）
  - **対象選択**: セル、個体群、個体、建物、財、マナ場そのもの、条件式によるフィルタ
  - **作用**: 世界の任意の層や量を増減・移送・変換する原始操作（温度、水分、標高、成長率、耐久、密度、価格、マナ…）
  - **修飾**: 増幅、持続、射程、遅延、分裂、連鎖、反転
  - **条件と制御**: 接触時、閾値、天体配置、反復、分岐、他の呪文の呼び出し
- **コストは自動算出。** 作用の大きさ × 範囲 × 持続 × 属性と土地の相性から必要マナを物理的に計算する。
  手作業の調整なしに任意の組み合わせが成立し、強い呪文ほど重くなる。
- **安定性**: グラフの複雑さと術者の技量の差が暴発率になる。暴発も同じ作用語彙で起きる。
- **安全で軽い実行**: 型検査（つなげない部品はつながらない）と、ステップ上限付きの決定論インタプリタ。
- **世界との結びつき**: 部品は技術ノードと同じ仕組みで研究・伝播・喪失する。文明は既知の部品から呪文を探索して編み出す。
  魔法生物の進化、マナ結晶の採掘と流通、魔法建築、魔導技術の枝、乱用によるマナ枯渇地帯。
- **ゴーレム・自動人形**: 部品に「センサー」（周囲の資源・敵・在庫・マナを読む）と「行動」（移動・採掘・運搬・売買・攻撃）を加え、
  呪文グラフを**毎 tick 実行される行動ルーチン**として素体に焼き付ける。素材が耐久とマナ容量を決め、稼働にはマナ維持費がかかる。
  プレイヤー不在でも採掘して市場に売る、集落を守る、といった自動化ができる。画面外では個別実行せず生産率などの集計値に畳んで軽くする。
  マナ切れや暴発で暴走した個体は遺跡のボスになりうる。文明も同じ仕組みで魔導機械を作る。
- **Spell Forge（UI）**: ノードをつないで呪文を組むエディタ。必要マナ・暴発率・効果予測をその場で表示。自然言語からローカル LLM が呪文グラフ案を作る。

### 9. 占星術システム (`systems/astrology`)

天体システムから実際に計算した空を使う。飾りではなく、世界に効く。

- **天体暦**: 観測地点から見た恒星・惑星・衛星の天球上の位置、食、合・衝・トラインなどのアスペクト、彗星を算出。
- **星座と黄道**: 背景恒星から文明ごとに星座を作り（命名は LLM / 手続き生成）、黄道を区分する。文明によって体系が違う。
- **文化としての占星術**（魔法なしでも動く）: 暦・祝祭・吉凶の前兆が集落の士気、意思決定、市場心理に影響する。
- **秘術としての占星術**（魔法有効時）: 天体と属性の対応表をルールで定義し、配置がマナの湧出と呪文の効きを変える。
  呪文の「条件」部品に天体配置を使える（例: 満月かつ特定の合のときだけ発動する儀式）。
- **出生図**: 個体・NPC・プレイヤーの誕生時の配置から、形質や属性親和への補正を導く。
- **天体工学・メガストラクチャー**: 環状列石・神殿・地上絵・軌道ミラーなど、**向きと緯度経度が意味を持つ建物**。
  `sky.ts` で実際に整列を判定し（例: 夏至の朝日が岩の隙間を通る）、成立した日だけ周囲のマナ湧出が数倍になって
  超広域の儀式魔法（天候操作・テラフォーミング）が可能になる。軌道ミラーは日射そのものを変えて気候に効く。
  天文学の技術と天体崇拝の価値観を持つ文明が自発的に建て、プレイヤーも設計できる（建設画面で整列日を予測表示）。
- **Sky Chart（UI）**: 天球図、今後の天文イベント、出生図の表示。

### 10. 宇宙進出 (`systems/space`)

- 技術ツリーの宇宙分野に沿って進む: ロケット → 人工衛星 → 有人飛行 → 軌道基地 → 月面基地 → 惑星間航行 → 入植 → テラフォーミング → （遠未来）恒星間船。
- **打ち上げと航行**: 必要 Δv を天体の質量と軌道から計算し、輸送コストに換算。惑星間は遷移窓（位置関係）で周期的に安くなる。
- **入植地**: 他天体の集落。生命維持の必需（空気・水・食料）を自給か輸入で満たす必要があり、失敗すれば滅びる。
- **惑星間経済**: 同じ市場・交易の仕組みが天体間に広がる。希少資源の天体が価値を持つ。
- **他の星の世界**: 各天体は同じシムコアで動く別ワールド。訪問・観測された時点でサブシードから生成し、活動がなければ粗く進める。
- **生命の移植と分岐**: 持ち込んだ種は新しい環境で別の進化をたどる。テラフォーミングは気候・炭素の仕組みをそのまま使う（技術でも魔法でも可）。

### 11. 言語・文化・宗教の進化 — ミーム生態系 (`systems/culture`)

生物のゲノム進化と同じ複製子エンジンを、文化形質にそのまま使う。

- **言語**: 集落ごとの音韻目録・音素配列・語彙傾向のベクトル。時間経過で音変化が積もり、山脈や海で隔離されると方言が分岐し、
  距離が閾値を超えると別言語として系統樹に記録する。交易で混ざり、文字・印刷の技術で変化が遅くなる。
- **言語距離のコスト**: 言語が遠いほど交易コスト（交渉・通訳）が上がり、技術伝播が遅れる。交易の多い経路では共通語が生まれる。
- **価値観**: 好戦性・自然崇拝・商業重視・伝統志向・信仰心などのベクトル。集落 AI の優先度（何を建てるか、何を研究するか、
  魔法への態度、戦うか）を決める。繁栄した集落の価値観ほど交易・移住・征服で広がる（選択）。
- **宗教・思想**: 出来事を引き金に変異発生する。大飢饉・疫病 → 終末信仰、日食・隕石・彗星 → 天体崇拝、豊穣 → 地母神信仰など。
  教義は価値観を補正し、神殿の建設優先度、聖地、分派、布教、戦争の動機に直結する。引き金と効果はルールで定義。
- **紛争**: 政体間の関係を持ち、資源圧と価値観・宗教の距離から戦争が起きる。結果は征服・破壊・難民で、破壊された街は遺跡になる。
- **命名への反映**: 音韻ベクトルから直接、地名・人名を手続き生成する（LLM なしで文化圏ごとに響きが揃う）。
  LLM があれば同じベクトルと価値観・宗教をプロンプトに渡し、都市名・人名・神話の文体を文化圏ごとに統一・変化させる。

### 12. 疫病・共生微生物 — ミクロ生態系 (`biosphere/pathogen.ts`, `symbiont.ts`)

- **病原体は特殊な種。** `感染力・致死率・潜伏期間・適温・宿主域・環境中の持続` のゲノムを持ち、複製子エンジンで進化する
  （感染力と致死率のトレードオフ、宿主の乗り換え）。
- **感染動態**: セル/集落ごとに感受性・感染・回復の区分を持ち、宿主密度に依存して広がる。集落間は交易路の流量と移住で運ばれる。
  家畜化や開墾で野生宿主との接触が増えると、動物由来の病気が人に移る。
- **連鎖**: 交易網と都市の高密度化 → パンデミック → 人口激減 → 技術の維持人数割れで失伝 → 耕作放棄地の森林再生 → CO2 吸収。
  既存の各 system がつながっているので、この連鎖は個別に実装しなくても起きる。
- **対応**: 流行が医療技術（薬草・衛生インフラ・検疫・ワクチン）と治癒魔法の研究優先度を引き上げる。検疫は交易を止めるので経済に響く。
- **共生体**: 宿主に利益を与える微生物（消化 → 食性幅、窒素固定 → 土壌と NPP、マナ共生 → マナ親和）。宿主と共進化する。

### 13. 地底・深海・空島 — 多層グリッド (`world/layers.ts`)

- **層**: 深海底 / 地下空洞 / 地表 / 高空 / 軌道。地表以外は**存在するセルだけ疎に確保**する。
  各セルは地表セルへの対応、横の隣接、上下リンク（縦穴・海溝・軌道エレベータ）を持つ。system からは普通のセルに見える。
- **生成**: 地下空洞は石灰岩の溶食・溶岩洞・断層から、深海の熱水噴出孔はプレート境界から、空島は魔法か低重力のルールから生まれる。
- **地殻変動との連動**: 火山・地震・侵食・採掘で縦穴が開閉する。開けば地表の生物が進出し、光のない環境で
  盲目・発光・化学合成依存の形質へ適応放散して独自の地下生態系になる（一次生産は化学合成・落下有機物・マナ）。
- **文明**: 地下の巨大空洞都市、反重力魔法による空中都市、軌道エレベータと軌道都市。建物の立地条件に層を指定できる。
- **遺跡と遺物**の主な埋蔵先でもある。

## 悠久の時間の扱い（時間レンズ）

| レンズ | 1 tick | 主に動くもの |
|---|---|---|
| 宇宙 | 〜1000 万年 | 恒星進化、軌道の長期変動、プレート |
| 地質 | 〜100 万年 | プレート、侵食、炭素循環、進化（生態は平衡近似） |
| 進化 | 〜1 万年 | 氷期、種分化、文明の興亡を統計的に要約 |
| 歴史 | 〜1 年 | 個体数動態、生産・交易・技術・建築、気候変動 |
| 現在 | 〜1 日 | 市場、天文イベント、季節、突発災害（リアルタイム） |

- 速い系を粗いレンズで回すときは時間積分ではなく準平衡解を使う（数値発散を防ぎ、計算も軽い）。
- **履歴**: キーフレームを IndexedDB に保存。任意時点は「直近キーフレーム + 決定論再計算」で復元。
- **分岐**: 過去の時点で介入すると別タイムラインとして保存。

## ルールパック（ツールの入力）

Zod で検証する JSON。セクション:
`constants` / `universe`（恒星系の生成則）/ `climate` / `biomes` / `traits` / `innovations` / `interactions` /
`goods` / `recipes` / `needs` / `tech` / `buildings` / `infrastructure` /
`magic`（有効・無効、湧出源、属性、部品定義）/ `astrology`（天体と属性の対応、アスペクト、影響の式）/ `space` / `events` /
`culture`（価値観の軸、宗教の引き金と教義、言語変化率）/ `pathogens` / `layers`（層の生成条件）/ `artifacts` / `scenarios`（災厄シナリオ）

式言語は四則・比較・論理・`min/max/clamp/lerp` と名前付き変数のみ (`core/rules/expr.ts`)。
同梱パック: 「Earth-like」（魔法なし・現実再現）と「Earth-like + Arcane」（魔法と秘術占星術あり）。

## 3D 表示と画面構成

- **Observe** — 3 段階のズームがつながる: 恒星系ビュー（軌道と天体）→ 惑星ビュー（ローポリの球、層切替は頂点カラー）→ 地表ビュー。
  層: 標高 / プレート / 気温 / 降水 / バイオーム / 種の分布 / 集落と交易路 / 価格 / インフラ / 技術水準 / マナ濃度。
  時間レンズと再生速度、セルインスペクタ、個体数・物価・CO2 のチャート、食物網、系統樹、年代記、神視点の介入。
- **Play** — 惑星上の 1 セルに降り立つ三人称 3D。セルを決定論サブシードでローポリ地形に展開し、
  個体群から生物（形質から体型を手続き生成）、集落から街と住人を実体化。空には実際の天体が動く。
  歩く・観察して図鑑に記録・採集/狩猟・売買・建築・遺跡探索・呪文の作成と詠唱・宇宙船での他天体への移動。
  - **考古学**: 集落が遺跡になるとき、その時点の技術・呪文庫・言語・出来事から遺物（碑文、失われた技術の設計図、古い呪文 AST の魔導書）を生成し、
    堆積で埋もれ侵食で露出する。発掘して現代の集落に持ち帰ると、言語距離に応じた時間で解読され、失われた技術が復興する。博物館に売ることもできる。
  - **フィールドワーク**: 新種・亜種を観察・スケッチすると図鑑が埋まり、観察を重ねるほど適温・食性・弱点などの内部値が開示される。
    指標の異常（外来種の異常繁殖、栄養段階の崩れ、流行、マナ枯渇）から依頼が自動発生し、間引きや天敵の移入で指標が戻れば達成。
  - **クロニクル・ウォーカー（憑依・転生）**: 不死の神視点アバターに加え、その時代の街に生まれた一人（商人・魔術師・開拓者・兵士）として寿命まで生きる。
    出生図と親の種族と集落の経済状況が初期能力と所持品になる。築いた交易路・編み出した呪文・建てた物は世界に残り、
    死後は時間を進めて子孫や別の街の住人に憑依し、過去の行いの影響を体験する。前世は年代記に歴史上の人物として載る。
- **Rules** — ルールパックのフォーム/JSON 編集、検証エラー。自然言語 → ローカル LLM → 差分案 → 承認で適用。
- **Tech Tree / Spell Forge / Sky Chart** — 技術グラフの閲覧、呪文の組み立て、天球図と出生図。
- **Lab** — 複数シード × パラメータ掃引をヘッドレス実行し、多様度・絶滅率・気温推移・物価安定度・技術到達年などを比較。
  - **災厄シナリオ**: 「産業革命期の文明に白亜紀末級の隕石」「恒星の赤色巨星化が始まる。宇宙進出は間に合うか」などのプリセットを
    ワンクリックで注入。中身は「発動条件 + イベント列」のスクリプトで、分岐とイベントの仕組みを再利用し、注入なしの対照と並べて
    生存・回復時間・失われた技術・脱出の成否を比較する。ルールパックで自作できる。
- **Export** — ユニバース/ワールド JSON（スキーマバージョン付き）、地形・モデルの glTF、マップ PNG、設定資料 Markdown、ルールパック、呪文。
  - **World Cartridge**: その世界を舞台にそのまま遊べるパッケージ（単一 HTML または JSON）。勢力図、主要都市と物価、
    ダンジョン（遺跡の階層と、絶滅危惧の大型捕食者や暴走ゴーレムなどのボス）、固有の呪文、図鑑、神話年表、言語の名前生成器を構造化して同梱。
    HTML 版は軽量テキスト RPG / ローグライクのランタイム込みで単体動作し、ローカル LLM をつなげばゲームマスターとして TRPG を進行する。

## ローカル LLM 連携

- `LLMProvider`: `chat(messages, {jsonSchema?})`。Ollama と OpenAI 互換の 2 実装。設定画面でエンドポイントとモデルを指定、接続テストあり。
- タスク: 種・地名・集落・文化・星座の命名 / 解説 / 年代記の叙述 / ルール草案 / 呪文グラフ草案 / 占いの文面 / 世界への質問応答 /
  神話と教義 / 碑文 / 依頼文 / World Cartridge のゲームマスター。
- 命名・文体系のタスクには、その文化圏の音韻ベクトル・価値観・宗教をプロンプトに渡して文化ごとの一貫性を出す。
- 構造化出力は JSON スキーマ指定 + Zod 再検証、失敗時は 1 回リトライ後フォールバック。出力は IndexedDB にキャッシュ。
- ブラウザから Ollama を呼ぶには `OLLAMA_ORIGINS` の設定が必要 → 接続失敗時に UI で手順を案内する。

## 実装マイルストーン

規模が大きいので、各段階の終わりで必ず「動いて見える」ものを残す順に積む。

- **M1 基盤と 3D 惑星** — プロジェクト初期化 (Vite/TS/Preact/Three/Vitest, `git init`)、rng/noise、測地線グリッド、ルールパックスキーマ + 式評価器、
  セル集合の抽象（後の多層・多天体のため）、Worker、ローポリ惑星の描画と層切替、時間再生、性能計測の土台。
- **M2 地殻変動** — プレート・造山・侵食・河川・火山・地震。
- **M3 天体と気候変動** — 恒星系生成、ケプラー軌道、日射と季節、エネルギー収支、炭素循環、氷床と海面、恒星系ビュー。
- **M4 生態系** — バイオーム、種・個体群、ecology/dispersal/events、チャート、年代記、IndexedDB 保存。
- **M5 進化と時間レンズ** — 汎用複製子エンジン、ゲノム・適応度・種分化・絶滅・革新、時間レンズ、キーフレームと時間遡行、分岐、系統樹・食物網。
- **M5.5 疫病と共生微生物** — 病原体を特殊な種として追加、感染動態、共生体。（人への流行と交易路伝播は M6 完了時に接続）
- **M6 文明と経済** — 集落、生産・消費、市場、交易路、土地利用、ライブ経済チャート。
- **M7 技術と建築** — 技術グラフのデータ整備、研究・普及・伝播・喪失、エネルギー転換と排出、建築キュー、インフラ、遺跡、建物の手続き生成。
- **M7.5 言語・文化・宗教** — 言語ベクトルと分岐、言語距離コスト、価値観、宗教の変異発生、政体と紛争、音韻からの命名生成。
- **M7.7 多層グリッド** — 地下空洞・深海・高空の疎セル、縦穴の開閉、地下生態系の適応放散、地下都市。（空中・軌道都市は M8 / M10 で解禁）

- **M9 占星術** — 天体暦、アスペクト、星座生成、文化的影響、マナへの影響、出生図、Sky Chart。

## 検証方法

- **決定論** (Vitest): 同一シード + ルールパック → 同一ハッシュ。キーフレームからの再計算が直通計算と一致。
- **不変条件**: 密度・在庫・価格が負にならない、絶滅種が復活しない、交易で財が保存される、炭素とマナの総量収支が合う。
- **現実性** (Earth-like): 軌道周期がケプラー第 3 法則に従う、赤道〜極の気温勾配、山脈の風下に乾燥帯、河川が海へ到達、
  CO2 増加で昇温し海面が上がる、バイオマスがピラミッド形、隔離陸塊で固有種が増える、供給ショックで価格が上がり交易で収束する、
  必要資源のない文明では該当技術が遅れる、技術普及が S 字になる。
- **技術・建築**: 前提を満たさない技術は取得されない、交易路沿いに伝播する、コスト不足の建物は完成しない、放棄後に遺跡が残る、道で輸送コストが下がる。
- **魔法**: 型の合わない部品接続を拒否する、コストが作用量に単調増加する、マナ不足では発動しない、インタプリタがステップ上限で必ず止まる、
  `magic` 無効のパックでは魔法関連の状態が一切生成されない。
- **占星術**: 天体暦が軌道計算と一致する、食とアスペクトが正しい時刻に検出される、同じ誕生時刻と場所から同じ出生図が出る。
- **宇宙**: Δv が天体の質量と軌道から期待値どおりに出る、遷移窓が周期的に現れる、生命維持を満たせない入植地が衰退する。
- **文化**: 隔離された集落間で言語距離が単調に開く、言語距離が交易コストと伝播速度に効く、引き金イベントの後にだけ対応する宗教が発生する、
  同じ音韻ベクトルから同じ名前列が生成される。
- **疫病**: 宿主密度が閾値未満なら流行が収束する、交易路でつながる集落へ先に広がる、検疫で伝播が落ちる、
  人口激減 → 技術失伝 → 耕作放棄 → 森林回復 → CO2 低下の連鎖が統合テストで再現される。
- **多層**: 縦穴のない層へは生物が移動しない、地下で光依存の一次生産がゼロになる、疎セルの確保数が存在セル数に一致する。
- **ゴーレム・天体建築**: ルーチンがステップ上限とマナ維持費を守る、画面外の集計化と個別実行で生産量が許容誤差内で一致する、
  整列日が天体暦と一致し、その日だけマナ倍率がかかる。
- **考古学・憑依**: 遺物の内容が滅亡時点の集落状態と一致する、解読時間が言語距離に単調増加する、解読で失伝技術が復活する、
  同じ誕生条件から同じ初期能力が出る、前世の業績が次の憑依時に世界に残っている。
- **Cartridge・シナリオ**: 書き出した HTML がネットワークなしで単体起動する、同梱データがスキーマを通る、
  シナリオ注入ありとなしの分岐が注入時点まで同一ハッシュである。
- **数値安定性**: 各レンズで長時間実行して発散しない。レンズ切替で状態が不連続に飛ばない。
- **性能**: tick 時間・フレーム時間・バンドルサイズ・tick 中のアロケーション量を計測し、予算超過でテスト失敗にする。
- **LLM**: モックプロバイダでスキーマ検証とフォールバック経路をテスト。実機は Ollama 起動状態で手動確認。
- **実機確認**: `npm run dev` を起動し、ブラウザペインで「生成 → 大陸が動く → 氷期が来る → 種が分化 → 文明が技術を進め街を建てる →
  物価が動く → 呪文を組んで唱える → 天球図を見る → 他の星へ移住 → 書き出し」を一通り操作。
